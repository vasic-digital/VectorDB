## Maintenance

Every CL that touches `pkg/client/client.go`, `pkg/i18n/translator.go`,
any backend's `client.go` / `config.go`, or the round-287 runner
(adds/removes/renames an exported symbol, alters `Vector` /
`SearchQuery` / `CollectionConfig` shape, registers a new backend,
adjusts a validation gate) MUST update this file in the SAME commit.
Drift is a CONST-048 violation. The Challenge runner asserts schema
invariants at runtime — adding a backend without extending the
runner's coverage is a paired CONST-035 violation.

Every CL adding a new locale to `supportedLocales()` in
`challenges/runner/main.go` MUST also update
`challenges/fixtures/locales.yaml` in the SAME commit. Drift between
the two is a CONST-046 violation.
